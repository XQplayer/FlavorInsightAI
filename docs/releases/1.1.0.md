# FlavorInsight AI 1.1.0

当前完整平台 / Current platform release. New product tag: `flavorinsight-v1.1.0`.

## 版本体系整理

本次将分散的 FlavorThresholdDB 旧编号和后续增量更新整理为统一的 FlavorInsight AI 发行入口。当前版本为 **1.1.0**，此前更新统一进入 **1.0.0 历史归档**。原始旧标签/提交保留，不挪用旧 `v1.1.0`；这不是功能退回，也不宣称下述既有功能全部在本次新实现。

## 当前包含的能力

- FlavorThresholdDB：CAS/中英文名称检索，香气阈值、风味描述和多源化合物证据；保留测量介质、类型、单位及来源。
- 岛津处理：浏览器内工作簿处理、CAS日期恢复、筛查、平行样处理、半定量、统计/QC与矩阵拆分。
- 可选分类/阈值信息、估算参考OAV和CV筛查，以及来源与失败原因审核信息。
- 任务编号＋名称、状态对应结果包名、恢复/重新运行、父任务关联、错误说明和本地历史证据。
- 已集成统计分析界面、可追溯导入和结果/复现报告导出；实际运算需要本机 Python/R 服务8890，GitHub Pages不托管该运算。
- 中英文界面、品牌展示及一致的首页/构建版本。

模型推理、风味预测及自动未知物鉴定不宣称已经实现；本地证据查询不等于AI模型生成。公开数据库关系不自动证明感官贡献或因果关系。此次未修改科研公式、原始数据、数据库结构或访问权限。
