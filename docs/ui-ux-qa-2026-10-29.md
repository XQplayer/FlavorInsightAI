## Known limits and follow-up

1. Vite still reports existing dependency warnings: RDKit externalizes browser-incompatible `fs`/`crypto` imports; bundled 3Dmol uses `eval`; a few chunks exceed 500 kB. No new dependency was introduced. Dependency upgrades and bundle splitting should be evaluated separately from this UI branch.
2. The local analysis service enforces an origin allowlist. The active, fully working isolated preview uses `http://127.0.0.1:5180/FlavorInsightAI/` with Python service `127.0.0.1:8890`. Port 5181 can show the UI but is not an allowed compute origin. The security allowlist was not widened.
3. One R resource-limit test failed once while Python and R suites ran concurrently; the standalone rerun and subsequent sequential nine-file R run passed. No engine code was modified.
4. `PlatformPages.css` still contains legacy selectors for the replaced homepage. They are unused by the new homepage but remain to avoid an unrelated cascade-risk cleanup in this visual release. Removing them can be a separate low-risk maintenance change.
5. The route/theme checks establish basic focus, keyboard and responsive behavior. They are not a full WCAG audit or cross-browser certification. Key computed contrast pairs pass AA normal text (action white 5.17:1, light heading/canvas 13.65:1, dark heading/surface 13.39:1). Cyan on white is only an accent (2.43:1) and must not be used as standalone body text.
6. The public GitHub Pages site has not been updated. The production artifact and nested routes were verified locally; merge and deployment require a separate rollout decision because the original `main` worktree contains unrelated local changes.
