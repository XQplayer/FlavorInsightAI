Their path difference does **not** isolate IndexedDB or localStorage. Supabase auth and cookies must be treated as potentially shared. Service Worker scope depends on registration path; none was used as evidence of full separation.

An independent-hostname preview is a release gate. The user confirmed the GitHub repository as the authority and reported no available independent subdomain or independently controlled static host. A separate Sites account was discoverable, but its ownership was not confirmed; no site was created and no credentials or real research data were sent there. Until a verified separate hostname is available, use **synthetic data only**. The current local preview `http://127.0.0.1:5262/FlavorInsightAI/data-analysis/` is served from Release 1 build and passed Chrome desktop/tablet/mobile checks; it is not an online isolation test.

Required acceptance on the separate host: different `location.origin`, no production IndexedDB/localStorage/cookies, no production Supabase session, no production data API calls, Worker served from its deployment base. Never clear formal-site user storage as a workaround.
