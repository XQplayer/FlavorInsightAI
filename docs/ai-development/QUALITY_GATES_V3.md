For new scientific algorithms: before implementation, require independent reference inputs/results with units, method/source, tolerances, invalid/boundary cases, versions and reviewer. Local R tests are mandatory until a reproducible public-runner setup exists. For deployment: resolve or explicitly accept the E2E issue, obtain real PR CI at the exact SHA, review residual security/science risks, get authorized release and a rollback target.
