Scope: integrate the existing immutable browser dataset and R PCA engine with a natural-language planning and explicit confirmation path. Preserve existing seven-step GC-MS Worker and source files. This is L4 because the requested endpoint is production publication.

1. Freeze the staging identity, five applied migrations, source hashes and 26/26 real-JWT probe in the existing RLS report. Compare production metadata read-only if a verified production read credential exists. Any new database migration needs a SQL diff, rollback and separate user approval.
2. Add bounded deterministic `inspect_dataset`, `recommend_analysis` and `prepare_analysis` helpers over the current browser-local dataset contract. Natural-language intent may suggest PCA but must not invent group independence. Hash the exact dataset snapshot, show missing/constant/mixed-unit/replicate warnings, allow editing parameters, and require confirmation. The request must bind the confirmed snapshot and recipe before invoking the current R analysis client.
3. Reuse existing R `pca` job, cancellation, results, scores/loadings/scree plots and exports. Persist plan evidence with the existing local run; send only a bounded result excerpt to GPT if a safe authenticated integration is available. A missing AI connection must not fabricate explanation.
4. Add tests for intent, inspection, stale hash, confirmation and result lineage. Run the independent R reference, focused frontend and Python tests, browser path, lint/build/audit/secret checks. Record actual results, not inferred passes.
5. Integrate main without touching the dirty root, then inspect CI and deploy triggers. Production release is blocked until the online R runtime, authentication, persistence, production permission diff and secret/flag settings have verified solutions. Prepare an exact high-risk change list before requesting the separately required approvals.

Inputs: an imported local dataset and user prompt. Outputs: a reviewable PCA plan and, only after confirmation, a genuine service job plus existing graphs/exports. Failures: no dataset, unsupported intent, invalid/mixed source, stale hash, offline engine, and permission or runtime errors remain explicit. Acceptance: synthetic PCA works end to end locally with independent reference values; no synthetic observation is presented as real research; only matching remote CI can clear the remote gate.
