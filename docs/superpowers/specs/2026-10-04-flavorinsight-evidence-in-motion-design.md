# FlavorInsight AI — Evidence in Motion visual refinement

Status: approved for local implementation on 2026-10-04. This refines, rather than replaces, the approved platform redesign specification.

## Intent

Make the entire platform feel like one considered scientific product. The brand surface tells the journey from instrument signal through CAS identity and sourced evidence to interpretation. Scientific workbenches stay legible and operational; optical effects never cover inputs, tables, QC states, or logs.

## Layout and design language

- Home: editorial masthead, one bespoke evidence-trajectory graphic, clear live entry points, then a paced research-chain narrative. Avoid repeated generic card grids and decorative metrics.
- Shared shell: precise product identity, stable navigation and controls. The floating optical treatment belongs only on brand pages; workbench navigation stays opaque.
- Database and search: retain current data semantics and sources, but give the module a clearer entry hierarchy and visual connection to the platform.
- Processing: preserve all seven analysis stages, configuration, import, monitoring, gate and download behavior. Improve only the framing and density of the work area.
- Analysis and resources: honest readiness and provenance. Planned capabilities have no pretend actions.

Use the approved mist/blue-gray/violet-gray/warm-white palette and one blue action family. Light and dark modes must use readable surfaces. In the brand hero, a restrained CSS/SVG diagram is a metaphor, not live analytical output. The real ethyl acetate example remains explicitly an example, with actual evidence governed by retrieval.

## Verification

Check semantic routes and labels, English/Chinese preference, light/dark, 1440/1024/768/375 layouts, keyboard focus, reduced motion/transparency, and all existing scientific tests. A visual refinement is not permission to change CAS, threshold, QC, OAV, sorting, or export rules. No GitHub publish is included in this local implementation request.
